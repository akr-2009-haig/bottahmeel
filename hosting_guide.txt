4) Hetzner Cloud (الأفضل سعراً وجودةً)
──────────────────────────────────────────────
الوصف:
  سيرفر VPS ألماني بأسعار منخفضة جداً وجودة عالية.

المزايا:
  ✅ أرخص VPS موثوق في السوق
  ✅ سرعة عالية (1Gbps)
  ✅ uptime 99.9%
  ✅ مناسب تماماً لـ 300k+ مستخدم
  ✅ تحكم كامل في السيرفر

العيوب:
  ❌ يحتاج معرفة بالـ Linux
  ❌ لا إعداد تلقائي (يدوي)

الإعداد من الهاتف (باستخدام Termius أو JuiceSSH):
  1. أنشئ حساباً على hetzner.com
  2. اطلب سيرفر CX11 (2GB RAM, 20GB SSD)
  3. حمّل تطبيق Termius من متجر التطبيقات
  4. اتصل بالسيرفر عبر SSH (IP + كلمة مرور)
  5. نفّذ الأوامر التالية:
     $ apt update && apt install -y python3 python3-pip git postgresql
     $ git clone https://github.com/YOUR_REPO/YOUR_BOT.git
     $ cd YOUR_BOT
     $ pip3 install -r requirements.txt
     $ nano .env   # أضف TELEGRAM_BOT_TOKEN و DATABASE_URL
     $ python3 run_bot.py &
  6. لتشغيل البوت دائماً استخدم:
     $ apt install -y supervisor
     $ nano /etc/supervisor/conf.d/mybot.conf
     [program:mybot]
     command=python3 /root/YOUR_BOT/run_bot.py
     autostart=true
     autorestart=true
     $ supervisorctl reread && supervisorctl start mybot

السعر: CX11: ~€4.5/شهر | CX21 (4GB): ~€8/شهر

8) Fly.io (موصى به للبوتات المتوسطة-الكبيرة)
──────────────────────────────────────────────
الوصف:
  منصة حديثة تجمع بين سهولة Heroku وأداء VPS.

المزايا:
  ✅ رصيد مجاني سخي شهرياً ($5)
  ✅ خوادم في مناطق متعددة
  ✅ Managed PostgreSQL ممتاز
  ✅ إعداد من الهاتف سهل
  ✅ مناسب لـ 300k+ مستخدم

العيوب:
  ❌ يحتاج Dockerfile
  ❌ واجهة command-line (CLI) أساساً

الإعداد من الهاتف:
  1. من متصفح الهاتف: افتح fly.io وسجّل حساباً
  2. حمّل Termius وتصل بسيرفر مؤقت لتنفيذ CLI
     أو استخدم GitHub Codespaces (مجاني)
  3. ثبّت flyctl:
     $ curl -L https://fly.io/install.sh | sh
  4. أنشئ fly.toml:
     app = "mybot"
     [build]
       dockerfile = "Dockerfile"
     [[services]]
       internal_port = 8080
  5. نشر البوت:
     $ fly auth login
     $ fly launch
     $ fly secrets set TELEGRAM_BOT_TOKEN=xxx DATABASE_URL=xxx
     $ fly deploy

السعر: مجاني ($5 رصيد شهري) / Paid: ~$10-30/شهر

📝 ملاحظات مهمة لـ 300,000+ مستخدم:

1. قاعدة البيانات:
   - استخدم PostgreSQL (مدعوم في هذا البوت)
   - فعّل connection pooling (مُفعَّل افتراضياً في هذا البوت)
   - أضف indexes (مُضافة تلقائياً عند تشغيل البوت)

2. الأداء:
   - البوت يستخدم Asyncio و python-telegram-bot المتزامن
   - الـ TTL Cache يُخفف الضغط على قاعدة البيانات

3. النسخ الاحتياطي:
   - اضبط pg_dump مجدولاً يومياً
   - احتفظ بنسخة في Google Drive أو Telegram Channel

4. المراقبة:
